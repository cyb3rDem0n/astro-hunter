# Astro Hunter development rules

- Scientific correctness takes precedence over implementation convenience.
- Do not change astronomical methodology without explicit approval.
- Keep acquisition, preprocessing, detection and interpretation separated.
- Every scientific algorithm must be documented.
- All numerical results must preserve units.
- Functions must be testable independently.
- Do not hard-code expected planetary periods.
- Do not use catalog values during signal detection.
- Keep raw observational data immutable.
